# SKILL 与 MCP 管理

这个插件把「模型这一次能看到哪些技能、能连哪些 MCP 服务器」搬到界面上，按全局、项目、会话三层分别管理。设置页里分 SKILL 管理、MCP 管理两页，另外各有侧边栏入口、对话页标签与输入框左下角的临时开关，用不用都可以在页头的「入口」里逐个开关。

## 三层作用域

| 作用域 | 覆盖谁 | 记录里的位置 |
| --- | --- | --- |
| 全局 | 这台机器上的每条会话 | `global` |
| 项目 | 某一个项目目录下的每条会话 | `projects[项目根]` |
| 会话 | 只这一条会话 | `sessions[会话 ID]` |

三层同时出现同一个名字时，最近的那一份说了算：会话盖过项目，项目盖过全局。把最近的这一份关掉，这个名字在当前作用域里整体消失，更远的层不会把它接回来。

## 技能

技能按存放它的 agent 分组，分组来自磁盘上的目录。DSH 自己的 `$DSH_HOME/skills`、`~/.agents/skills`、`.dsh/skills`、`.agents/skills` 是内置读取的目录；Claude Code、Codex、Gemini、Cursor、Copilot、OpenCode、Windsurf、Trae、Qoder、Roo、CodeBuddy、WorkBuddy、OpenClaw 这些 agent 的目录按约定自动发现，目录不存在就不显示。除此之外可以手动添加任意目录作为一个来源。

- 来源可以整组停用，也可以只停用其中某几个技能；整组关着时单独打开某几个，来源会显示为开着。
- 新建技能写进所选来源的目录，可以选择「一个技能一个目录」或者「一个技能一个文件」，写入前能看到完整的 SKILL.md 与路径。
- 编辑改名字等于改目录名，说明与正文直接写进 SKILL.md。
- 删除会把整个目录或文件删掉，确认框里写明具体删什么。

停用不改动磁盘上的任何文件，只影响模型能不能看到这个技能。每个停用的名字都在它所在的那一层留一条同名占位，两个调用开关都关掉、排名比它自己的来源再靠前一位，注册表先去重同名再取靠前的那条，于是这个名字从模型清单和斜杠菜单里一起消失。

## MCP 服务器

服务器同样按范围管理，最近的那个范围里同名服务器生效。支持两种连接方式：本地进程（命令加参数，插件负责启动与退出）与 HTTP（连到已经在跑的地址）。保存后立刻连接，卡片上显示工具数量与工具名，工具以 `mcp__名称__` 前缀出现在模型里。停用或删除时进程与连接一起断开。

## 这一次发送带什么

输入框左下角有一个 `能力` 按钮，打开后列出这条会话能看到的全部技能与服务器，按来源分组。在这里关掉的只这一回合生效，发完就恢复原样。它比项目与全局都近，用来临时腾出上下文、临时换一个服务器。

## 记录文件

所有开关与自定义目录都记在 `~/.dsh/dsh-skill-mcp-manager/store.json`。这个文件归设置页管理，手工编辑后刷新页面即可重新读取。
